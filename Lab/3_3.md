Bước 1. Tạo namespace
kubectl create ns lab
kubectl config set-context --current --namespace=lab
Bước 2. Tạo ServiceAccount

serviceaccount.yaml

apiVersion: v1
kind: ServiceAccount
metadata:
  name: movie-reader
  namespace: lab

Apply

kubectl apply -f serviceaccount.yaml

Kiểm tra

kubectl get sa

Kết quả

NAME
default
movie-reader
Bước 3. Tạo Role

Mình chỉ cấp quyền đọc Pod.

role.yaml

apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: movie-reader-role
  namespace: lab

rules:
- apiGroups: [""]
  resources:
    - pods
  verbs:
    - get
    - list
    - watch

Apply

kubectl apply -f role.yaml
Bước 4. Tạo RoleBinding

rolebinding.yaml

apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: movie-reader-binding
  namespace: lab

subjects:
- kind: ServiceAccount
  name: movie-reader
  namespace: lab

roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: Role
  name: movie-reader-role

Apply

kubectl apply -f rolebinding.yaml
Bước 5. Tạo Pod

Vì bạn luôn build sẵn movie-service, ta dùng luôn image đó.

pod.yaml

apiVersion: v1
kind: Pod
metadata:
  name: movie-api-client
  namespace: lab

spec:
  serviceAccountName: movie-reader

  containers:
  - name: app

    image: movie-service:latest

    imagePullPolicy: IfNotPresent

    command:
      - sleep
      - infinity

Apply

kubectl apply -f pod.yaml

Đợi Running

kubectl get pod
Bước 6. Kiểm tra ServiceAccount
kubectl describe pod movie-api-client

Bạn sẽ thấy

Service Account: movie-reader
Bước 7. Kiểm tra Role
kubectl get role
movie-reader-role
Bước 8. Kiểm tra RoleBinding
kubectl get rolebinding
movie-reader-binding
Bước 9. Verify RBAC (đây là bước quan trọng nhất)

Thử quyền được cấp

kubectl auth can-i list pods \
--as=system:serviceaccount:lab:movie-reader \
-n lab

Kết quả

yes

Thử quyền không được cấp

kubectl auth can-i delete pods \
--as=system:serviceaccount:lab:movie-reader \
-n lab

Kết quả

no

Thử đọc Secret

kubectl auth can-i get secrets \
--as=system:serviceaccount:lab:movie-reader \
-n lab

Kết quả

no

Điều này chứng minh RBAC đang hoạt động đúng.

Bước 10. Kiểm tra ServiceAccount Token

Do máy bạn đang gặp lỗi kubectl exec, ta xác minh bằng YAML:

kubectl get pod movie-api-client -o yaml

Bạn sẽ thấy:

serviceAccountName: movie-reader

và volume kiểu:

projected:

được Kubernetes tự động mount chứa:

token
ca.crt
namespace

Đây là cơ chế mà Pod dùng để xác thực với Kubernetes API.

Nếu sau này kubectl exec hoạt động

Bạn có thể chạy:

TOKEN=$(cat /var/run/secrets/kubernetes.io/serviceaccount/token)

curl \
-H "Authorization: Bearer $TOKEN" \
--cacert /var/run/secrets/kubernetes.io/serviceaccount/ca.crt \
https://kubernetes.default.svc/api/v1/namespaces/lab/pods

và sẽ nhận được danh sách Pod trong namespace lab.
